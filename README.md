# Трекер целей

Личный трекер целей, привычек, задач и учёбы: ставишь измеримую цель со сроком
(«прочитать 480 страниц к 19 октября») или привычку («зал 3 раза в неделю»), записываешь дела
и повторяешь изученное, а экран «Сегодня» показывает, что сделать сегодня, чтобы ничего важного не упустить.

Архитектура, модель данных и план развития — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что уже работает

- цели с числом, единицей измерения, сроком и приоритетом;
- привычки: каждый день или N раз в неделю, норма за раз, отметка одним нажатием, серия
  с «заморозкой» (один пропуск в неделю не обнуляет серию), выполнение за 4 недели и календарь;
- обзор недели за 10 минут: входящие, отстающие цели и привычки, повторения, фокус на неделю
  (до 3 пунктов, видно на «Сегодня») и заметка «что получилось, что мешало»;
- сферы жизни (чтение, языки, спорт…): свои названия, цвета и иконки;
- записи прогресса по дням, включая прошедшие дни;
- экран «Сегодня»: итог дня, фокус недели, задачи, привычки, повторения и нормы по целям в одном месте;
- быстрая запись из любого места (кнопка «Записать» или клавиша N) во «Входящие» и их разбор;
  трекер понимает текст: «законспектировать лекцию 5 до пт !важно #учёба»;
- задачи: важность, дедлайн и день «когда делаю» отдельно, подзадачи, матрица «важно / срочно»,
  перенос невыполненного на завтра одной кнопкой, повторы («каждое вс», «по будням»);
- проекты: вехи с задачами, следующий шаг, связь с целью, пауза;
- расчёт нормы в день, отставания или опережения, серии дней подряд;
- страница цели с графиком «факт против плана» и историей;
- список всех целей с фильтром по сферам, архив;
- знания: материалы (книги, курсы, лекции) с частями и задачами-конспектами, заметки с вопросами
  для самопроверки;
- сессия повторения по расписанию 1 → 3 → 7 → 16 → 35 дней с оценкой «как вспомнилось»,
  лестница освоения из 5 уровней и самооценка «смог бы объяснить другому?»;
- заметки из Obsidian: шаблоны, инструкция и синхронизация с папкой хранилища
  (см. [obsidian/README.md](obsidian/README.md));
- мягкие лимиты нагрузки: повторений в день (лишнее переносится), материалов в «Изучаю»,
  долг повторений, строгий режим и прогноз нагрузки на две недели;
- отпуск: повторения и привычки на паузе, расписание сдвигается, серии не прерываются;
- резервная копия в файл и восстановление из него, миграции данных между версиями;
- светлая и тёмная тема, мобильная вёрстка;
- вход по почте и паролю: данные хранятся на сервере (Django REST Framework, PostgreSQL)
  и одинаковые на телефоне и компьютере; при коротком обрыве связи правки дожидаются её;
- развёртывание на своём сервере: Docker, PostgreSQL, HTTPS-сертификат, который получается сам,
  резервные копии базы каждую ночь, при желании — ещё и в облако.

Следующий шаг — Telegram-бот с утренней сводкой и напоминаниями, план — в [docs/PRODUCT.md](docs/PRODUCT.md).

## На своём сервере

Трекер по адресу `https://ваш-домен` на самом простом VPS (1 ГБ памяти): четыре контейнера Docker,
сертификат и копии базы — автоматически. Пошагово, от покупки сервера до переноса данных, —
в [docs/DEPLOY.md](docs/DEPLOY.md). Коротко:

```bash
git clone https://github.com/RAKOVpy/tracker.git && cd tracker
git checkout claude/fervent-faraday-f7chiv                      # пока последние этапы не в main
cd deploy && ./setup.sh tracker.example.ru                      # .env с доменом и паролями
docker compose up -d --build                                    # сборка и запуск
```

Затем откройте сайт и зарегистрируйтесь: первый аккаунт становится администратором и в «Настройках» →
«Сервер» открывает и закрывает регистрацию, выдаёт временный пароль вместо забытого и удаляет аккаунты.

## Запуск на своём компьютере

Понадобятся [Git](https://git-scm.com/), [Python](https://www.python.org/) 3.10 или новее
и [Node.js](https://nodejs.org/) 20.19+ или 22.12+.

**1. Код.**

```bash
git clone https://github.com/RAKOVpy/tracker.git
cd tracker
git checkout claude/fervent-faraday-f7chiv    # ветка с последними этапами, пока они не в main
```

**2. Сервер (первое окно терминала).** Подробности — в [backend/README.md](backend/README.md).

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver 8000
```

На Windows вместо `python3` — `python` (или `py`), вместо `.venv/bin/` — `.venv\Scripts\`:
`.venv\Scripts\pip install -r requirements.txt`, `.venv\Scripts\python manage.py migrate` и так далее.
Без настроек сервер работает в режиме разработки, данные — в файле `backend/db.sqlite3`.

**3. Фронтенд (второе окно терминала).** Создайте файл `frontend/.env.local` с одной строкой
`VITE_API_URL=/api` — так фронтенд работает через сервер, одинаково на любой системе. Затем:

```bash
cd frontend
npm install
npm run dev          # http://localhost:5173
```

**4.** Откройте http://localhost:5173, нажмите «Зарегистрироваться» и создайте аккаунт — он хранится
только в вашей базе. На пустом экране «Сегодня» кнопка «Показать пример» создаст цели и привычки
с историей, а в пустом трекере — ещё материалы с заметками, задачи, проекты и обзор недели.

**Демо-версия.** Чтобы показать трекер или посмотреть все возможности сразу, создайте демо-аккаунт
с историей за четыре месяца и хранилищем Obsidian к нему. В папке `backend`:

```bash
.venv/bin/python manage.py demo      # Windows: .venv\Scripts\python manage.py demo
```

Вход: `demo@tracker.local`, пароль `demo1234`. Что посмотреть и как подключить Obsidian —
в [docs/DEMO.md](docs/DEMO.md).

Без сервера (данные в этом браузере, входить не нужно) — тот же `npm run dev` без файла `.env.local`.

Синхронизация с Obsidian читает папку хранилища прямо в браузере: в Chrome и Edge папку достаточно
выбрать один раз, в Firefox и Safari — при каждой синхронизации.

```bash
npm test         # юнит-тесты (Vitest)
npm run lint     # oxlint
npm run build    # проверка типов и сборка
```

Тесты сервера — в [backend/README.md](backend/README.md).
