# Трекер целей

Личный трекер долгосрочных целей: ставишь измеримую цель со сроком
(«прочитать 480 страниц к 19 октября»), каждый день отмечаешь прогресс,
а приложение показывает норму на сегодня и идёшь ли ты по плану.

Архитектура, модель данных и план развития — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что уже работает (MVP)

- цели с категорией, единицей измерения, целевым числом, сроком и приоритетом;
- записи прогресса по дням, включая прошедшие дни;
- экран «Сегодня»: что нужно сделать сегодня, быстрая запись прямо с карточки;
- расчёт нормы в день, отставания или опережения, серии дней подряд;
- страница цели с графиком «факт против плана» и историей;
- архив, светлая и тёмная тема, мобильная вёрстка.

Пока данные хранятся в браузере (localStorage). Бэкенд на Django REST Framework — следующий этап.

## Запуск

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
```

```bash
npm test         # юнит-тесты (Vitest)
npm run lint     # oxlint
npm run build    # проверка типов и сборка
```

На пустом экране есть кнопка «Показать пример», она создаёт три демо-цели с историей.
