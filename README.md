# Трекер целей

Личный трекер долгосрочных целей: ставишь измеримую цель со сроком
(«прочитать 480 страниц к 19 октября»), каждый день отмечаешь прогресс,
а приложение показывает норму на сегодня и идёшь ли ты по плану.

Архитектура, модель данных и план развития — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что уже работает

- цели с числом, единицей измерения, сроком и приоритетом;
- сферы жизни (чтение, языки, спорт…): свои названия, цвета и иконки;
- записи прогресса по дням, включая прошедшие дни;
- экран «Сегодня»: что нужно сделать сегодня, быстрая запись прямо с карточки;
- расчёт нормы в день, отставания или опережения, серии дней подряд;
- страница цели с графиком «факт против плана» и историей;
- список всех целей с фильтром по сферам, архив;
- знания: материалы (книги, курсы, лекции) и заметки с вопросами для самопроверки;
- сессия повторения по расписанию 1 → 3 → 7 → 16 → 35 дней с оценкой «как вспомнилось»,
  лестница освоения из 5 уровней и самооценка «смог бы объяснить другому?»;
- заметки из Obsidian: шаблоны, инструкция и синхронизация с папкой хранилища
  (см. [obsidian/README.md](obsidian/README.md));
- резервная копия в файл и восстановление из него, миграции данных между версиями;
- светлая и тёмная тема, мобильная вёрстка.

Пока данные хранятся в браузере (localStorage). Бэкенд на Django REST Framework появится позже,
план — в [docs/PRODUCT.md](docs/PRODUCT.md).

## Запуск

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
```

```bash
npm test         # юнит-тесты (Vitest)
npm run lint     # oxlint
npm run build    # проверка типов и сборка
```

На пустом экране есть кнопка «Показать пример», она создаёт три демо-цели с историей.
